## 🚀 Getting Started

### Prerequisites
Before running the programs, make sure you have:
- **C++ Compiler** (GCC 7.0+ or equivalent)
- **IDE/Editor**: [VSCode](https://code.visualstudio.com/) (recommended) or any C++ compatible editor
- Basic knowledge of **C++ syntax** and **OOP concepts**

---

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/suray-marag-pandit/DataStructureAndAlgo.git
   cd DataStructureAndAlgo
````

2. **Open in VSCode:**

   ```bash
   code .
   ```

3. **Compile and run any program:**

   ```bash
   g++ -o program filename.cpp
   ./program
   ```

## 💻 Usage

### Running Examples

Navigate to any topic folder and compile the desired program:
