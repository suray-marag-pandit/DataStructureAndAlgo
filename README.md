
# DataStructureAndAlgo

A collection of C++ and C implementations for classic data structures and algorithms.  
Started: January 13th, 2024

## Project Structure

```
DataStructureAndAlgo/
├── Basics/                # Fundamental concepts and error handling
├── BackTracking/          # Backtracking problems (N-Queen, Rat Maze, Sudoku)
├── BinarySeachTree/       # Binary Search Tree implementations
├── BinarySearchTreePractice/
├── BinaryTree/            # Binary Tree algorithms
├── DynamicProgramming/    # DP problems and solutions
├── gfg/                   # Solutions from GeeksforGeeks
├── graphs/                # Graph algorithms
├── Hashmaps/              # Hashmap implementations and usage
├── Heaps/                 # Heap data structures
├── LinkedList/            # Linked list algorithms
├── Practice/              # Miscellaneous practice problems
├── Recursion/             # Recursive algorithms
├── Sorting/               # Sorting algorithms (Bubble, etc.)
├── Stack/                 # Stack data structures
├── STL/                   # Standard Template Library usage
├── Trie/                  # Trie data structure
├── bitwiseOperation.cpp   # Bitwise operations
├── Bubblesirt.cpp         # Bubble sort implementation
├── demo.c / demo.cpp      # Demo files
├── g.cpp                  # Miscellaneous code
├── README.md              # Project documentation
└── .vscode/               # VSCode configuration
```

## Highlights

- **Hashmaps**  
     Usage of `std::map` and `std::unordered_map` for key-value storage.  
     Concepts: bucket array, hash functions, mapping strings to array indexes and values.

- **BackTracking**  
     Classic problems: N-Queen, Rat Maze, Sudoku.

- **Sorting**  
     Bubble sort and other sorting algorithms.

- **Binary Trees & BSTs**  
     Implementation and practice files for binary trees and binary search trees.

- **Dynamic Programming, Graphs, Heaps, Linked Lists, Stack, Trie**  
     Comprehensive coverage of core data structures and algorithms.
